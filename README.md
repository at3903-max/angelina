# Pomodoro Timer

A small SwiftUI Pomodoro timer app that runs in Xcode.

## Features

- Freely set the countdown duration with hour, minute, and second fields.
- Start, pause, and stop the countdown.
- Large live countdown display with running, paused, ready, and finished states.

## Running

Open `PomodoroTimer.xcodeproj` in Xcode and run the `PomodoroTimer` scheme on an iOS simulator or device.
